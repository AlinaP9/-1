Пусть \(u_1(x, t)\) и \(u_2(x, t)\) — два ограниченных решения рассматриваемой задачи (I),\[|u_1| < M, \quad |u_2| < M,\]
где \(M > 0\) — некоторое число.

Разность этих функций\[v(x, t) = u_1(x, t) - u_2(x, t)\]ограничена (\(|v| < 2M\)), удовлетворяет уравнению (61) и однородным граничным условиям\[v(0, t) = 0, \quad v(l, t) = 0.\]

Коэффициенты Фурье для функции \(v\)\[v_n(t) = \frac{2}{l} \int_0^l v(x, t) \sin \frac{\pi n}{l} x \, dx,\]очевидно, удовлетворяют уравнению\[\ddot{v}_n + a \dot{v}_n + \omega_n^2 v_n = 0 \quad (\omega_n = \frac{\pi n}{l} a),\]так как вторые производные функции \(v(x, t)\) непрерывны для \(0 \leq x \leq l\).

Общее решение уравнения (*) имеет вид\[v_n(t) = A_n e^{a_n^{(1)} t} + B_n e^{a_n^{(2)} t},\]где \(a_n^{(1)}\) и \(a_n^{(2)}\) — корни характеристического уравнения, равные\[a_n^{(1)} = -\frac{\alpha}{2} + \sqrt{\frac{\alpha^2}{4} - \omega_n^2}, \quad 
a_n^{(2)} = -\frac{\alpha}{2} - \sqrt{\frac{\alpha^2}{4} - \omega_n^2} \quad (\alpha > 0).\]Так как \(\alpha > 0\), то \(\operatorname{Re} a_n^{(1,2)} < 0\). Следовательно, решение (**) уравнения (*) будет ограниченным при \(t \to -\infty\) лишь при \(A_n = 0\) и \(B_n = 0\), т. е. \(v_n(t) = 0\) для любого \(n\).

Таким образом,\[
v(x, t) \equiv 0 \quad \text{и} \quad u_1(x, t) = u_2(x, t).\]

\subsection*{8. Сосредоточенная сила}

Рассмотрим задачу о колебаниях струны под действием сосредоточенной силы, приложенной в точке \(x = x_0\). Если сила распределена на некотором участке \((x_0 - \varepsilon, x_0 + \varepsilon)\), то решение находится по формуле (55). Совершая предельный переход при \(\varepsilon \to 0\), можно получить решение поставленной задачи.

С другой стороны, при выводе уравнения колебаний мы видели (см. (8), п. 1 §1), что в точке \(x_0\), к которой приложена сосредоточенная сила, происходит разрыв первой производной, а сама функция остается непрерывной. Решение задачи \(u(x, t)\) о колебаниях струны под действием силы, сосредоточенной в точке \(x_0\), можно представить двумя различными функциями:\[u(x, t) = u_1(x, t) \quad \text{при} \quad 0 \leq x \leq x_0,\]\[u(x, t) = u_2(x, t) \quad \text{при} \quad x_0 \leq x \leq l.\]
